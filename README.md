# 🌸 Iris Flower Classification using Machine Learning

## 📌 Project Overview
This project was developed as part of my **CodeAlpha Machine Learning Internship**. It uses Machine Learning techniques to classify Iris flowers into three different species based on their sepal and petal measurements.

## 🎯 Objectives
- Understand the Iris flower dataset.
- Perform data preprocessing and analysis.
- Build a Machine Learning classification model.
- Evaluate model performance.

## 🛠️ Technologies Used
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📊 Project Features
- Data preprocessing
- Exploratory Data Analysis (EDA)
- Train-test splitting
- Logistic Regression model
- Model prediction
- Accuracy evaluation
- Confusion Matrix
- Data visualization

## 📂 Project Structure
- `Iris.csv` - Dataset
- `Iris_Classification (2).ipynb` - Jupyter Notebook containing implementation
- `accuracy.png` - Model accuracy visualization
- `confusion_matrix.png` - Confusion matrix
- `heatmap.png` - Correlation heatmap
- `histogram.png` - Data distribution
- `boxplot.png` - Boxplot visualization
- `pairplot.png` - Pairplot visualization
- `scatterplot.png` - Scatterplot visualization

## 🚀 How to Run
1. Clone this repository.
2. Install the required Python libraries.
3. Open the Jupyter Notebook.
4. Run all cells to execute the project.
